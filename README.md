# TypistLocal

Autocomplete that stays on your Mac. As you type, a suggestion appears in
gray at your cursor, in most Mac apps. A language model on your Mac writes
it; nothing you type leaves the machine.

**[Download for Mac](https://github.com/edouardGT/typistlocal/releases/latest)**
· [Website](https://edouardgt.github.io/typistlocal/)
· [Privacy](https://edouardgt.github.io/typistlocal/privacy.html)
· [Setup and help](https://edouardgt.github.io/typistlocal/help.html)

- `Tab` takes the next word, `Cmd + →` the whole suggestion, `Esc` dismisses it.
- Requires a Mac with Apple Silicon, macOS 14 or later, and about 4 GB of
  disk for the model, which the app downloads once on first launch.
- Free to download and use. Updates arrive through the app.

Problems or ideas: [open an issue](https://github.com/edouardGT/typistlocal/issues).

This repository holds the website (`site/`, published with GitHub Pages),
the update feed (`site/appcast.xml`) and the releases. The app's source code
is not public.
