Set up

  1. Install

    Download the disk image, open it and drag the app to your Applications folder. Open it from there.

    A small icon appears in the menu bar: two lines and a cursor. There is no Dock icon. Everything is in that menu.

  2. Allow Accessibility

    The app reads the text at your cursor through Accessibility, so it needs your permission. macOS asks the first time. If you missed it:

    1. Open System Settings → Privacy & Security → Accessibility.
    2. Turn on TypistLocal. If it is not in the list, click + and choose it in Applications.

    Use Privacy & Security, not the other Accessibility. System Settings also has an Accessibility item of its own, for VoiceOver, Zoom and the like. That one has no switch for this app. The list you need is inside Privacy & Security.

    Shortcut: until access is granted, the first item in the app’s menu reads Allow Accessibility Access…. Choose it and the right page opens.

  3. Get the model

    The model is a 3.85 GB file, downloaded once from Hugging Face. The setup window that opens on first launch downloads it for you. It shows progress, picks up where it stopped if the connection drops or you quit, and checks the file before using it.

    Closed the window? Click the menu bar icon and choose Set Up TypistLocal….

    When it is done, the app loads the model, which takes a few seconds, and the first line of the menu reads Model ready (gemma-4-E2B, on this Mac).

  4. Try it

    Open TextEdit and type I am truly grat. The rest of the word appears in gray at the cursor, often with a few more words. Press Tab to take one word.

  5. Opens at login

    The first time it runs from Applications, the app turns on opening at login, so suggestions are there after a restart. Turn it off with Open at Login in the menu.

Use

Keys

Tab
Takes the next word. Each press takes one more.
⌘ →
Takes the whole suggestion.
Esc
Dismisses it.
⌘ ⇧ Space
Opens the notes panel. Tab inserts the top result.

Holding Tab down takes one word, like a single press. After you take the last word of a suggestion, a Tab within the next second does nothing. That keeps a quick extra press from moving you to the next field.

The menu

  • Pause Inline Completion stops suggestions everywhere until you choose Resume Inline Completion.
  • Longer Suggestions lets a suggestion go on while the model is less sure: more words, a few more of them wrong at the end. On by default.
  • Learn From My Writing keeps messages you send, encrypted on this Mac, and uses a few related ones as examples. On by default.
  • Forget My Writing… deletes everything kept so far. It shows how many messages are kept.
  • Show Suggestions opens the notes panel.
  • Reindex reads your notes again after you edit them.
  • Open Knowledge Folder opens your notes folder in Finder.
  • Open at Login and Quit.

Your notes

Put Markdown files (.md) in ~/TypistLocal/knowledge/. Separate snippets with a line of three dashes:

# Friendly follow-up

Thanks for the update. I'll check this further and come back with my findings.

---

# Next snippet

What you are writing is used to search them, and the best matching passages go to the model as reference. Choose Reindex after you edit them.

Not there yet

There is no settings window, and no way yet to switch suggestions off in one app only. Pause works for all apps at once.

Settings

Until there is a settings window, these are changed in Terminal.

Stop reading the chat above the box

defaults write com.coffeetableconsultancy.TypistLocal \
  includeScreenContext -bool false

Let suggestions use the clipboard

Off by default. Items that password managers mark as concealed are skipped either way.

defaults write com.coffeetableconsultancy.TypistLocal \
  includeClipboard -bool true

Never learn from certain apps

Terminals and password managers are always left out. To add more, list them by bundle identifier. The command replaces the previous list, so name every app each time:

defaults write com.coffeetableconsultancy.TypistLocal \
  writingExcludedApps -array com.apple.Notes

Use another model file

Any GGUF model file. Quit and reopen the app afterwards.

defaults write com.coffeetableconsultancy.TypistLocal \
  modelPath ~/Models/other.gguf

Undo a setting

defaults delete com.coffeetableconsultancy.TypistLocal \
  includeScreenContext

Troubleshooting

The menu says “Allow Accessibility Access…”

The permission is not granted yet. Choose that item and turn the app on under Privacy & Security → Accessibility. See step 2.

The menu says “Model not downloaded”

The model file is not in place. Choose Set Up TypistLocal… in the menu and let it download (step 3). If you set another model file, the menu says “Model missing” with the path it looked at: check the modelPath setting.

The menu says “Model failed to load”

The file may be incomplete. A complete one is 3,845,328,608 bytes. Check with:

stat -f %z ~/Library/Application\ Support/TypistLocal/Models/*.gguf

If the number differs, delete the file and download it again.

No gray text appears

  • If the menu shows Resume Inline Completion, suggestions are paused.
  • Right after a finished sentence, or at the start of a line, it waits for your first letter.
  • It only shows words the model is fairly sure of, so sometimes there is nothing to show.
  • Password fields, address bars, search fields and login dialogs are left alone on purpose.
  • Some apps do not share their text through Accessibility. It cannot work there.

Two suggestions at once, or Tab acts strangely

Another autocomplete tool is running. Both draw gray text and both want Tab. Quit one of them.

Mid-word suggestions in another language are off

Add the language under System Settings → General → Language & Region. The app checks unfinished words against your preferred languages.

The gray text shows up in screen sharing

It is drawn on screen like any window, so a shared screen or a recording shows it. Press Esc to hide it, or pause from the menu while you share.

Still stuck? Open an issue on GitHub.

Uninstall

  1. Quit

    In the menu, turn off Open at Login, then choose Quit.

  2. Remove the app

    Drag it from Applications to the Trash.

  3. Remove what it kept

    The model and your encrypted writing:

    rm -rf ~/Library/Application\ Support/TypistLocal

    The encryption key in your login keychain:

    security delete-generic-password -s TypistLocal -a writing-key

    The settings:

    defaults delete com.coffeetableconsultancy.TypistLocal

    Your notes folder and its search index. It holds your own notes, so keep a copy of any you want first:

    rm -rf ~/TypistLocal

  4. Remove the permission

    In System Settings → Privacy & Security → Accessibility, select the app and click −.
